# NyayShorts - 100-Word Legal Rulings App

An authentic, open-source mobile application (PWA) inspired by Inshorts, tailored for Supreme Court, High Court, and District Court rulings in 100 words.

## 🚀 Features Included:
- **Vertical Card Swipe:** Gesture-based smooth swiping powered by Swiper.js.
- **Direct Supabase Live Sync:** Rulings fetched directly from your free PostgreSQL database.
- **Offline & Bookmarks:** Advocates and law students can star cases to read offline anytime.
- **Instant Search:** Search across rulings by title, citation, or legal term (e.g., *Bail*, *Section 138*).
- **Court & Practice Area Filters:** Supreme Court, High Courts, District Courts, Criminal, Constitutional, Arbitration, etc.
- **WhatsApp & Social Share:** Pre-formats the case title, citation, and 100-word ratio for legal forums.
- **Progressive Web App (PWA):** Installs directly to iPhone and Android home screens without App Store fees.

## 📁 Project Structure:
- `index.html` - The complete mobile application UI and logic
- `manifest.json` - PWA configuration for mobile home screen installation
- `sw.js` - Offline caching engine (Service Worker)
